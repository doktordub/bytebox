# Changelog

All notable changes to ByteBox will be documented in this file.

## [Unreleased]

### Added

- `src/bytebox` package layout.
- `src/memory_store` transition shim for one rebrand release.
- ByteBox CLI entrypoint and sample config rename.
- contributor, security, release, and support documentation.
- pre-commit configuration and initial CI workflow skeleton.

### Changed

- canonical distribution, import, API title, and example docs now use ByteBox branding.
- default database path changed to `./data/bytebox`.
- default ingest manifest name changed to `.bytebox_ingest_manifest.json`.
- environment configuration prefix changed to `BYTEBOX_`.
